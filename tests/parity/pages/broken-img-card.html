D. Filler, so the page is taller than a viewport

A catalogue front page is mostly thumbnails, and a browser that blocks third-party images by default renders it as a page of alt text. How that alt text is boxed decides whether the grid keeps its shape.

An unavailable image still occupies the box its width and height give it. The alternative text is painted inside that box, not flowed through the page as if the element were a paragraph.

When the alt text is allowed to resize the box, a card grows to fit a title it already displays beneath the thumbnail, and the grid stretches to several times its real height.

The control section is what the same cards cost with no image element at all, so the difference between the two is exactly the price of the alternative text.

Every measurement in this file is taken at the same paint width the parity harness uses, with the reference renderer offline, so neither engine is loading anything the other cannot.

Freedom blocks third-party subresources by design. The reference renderer is configured to match, so a difference in this page is a difference in layout.

The image is unavailable in both engines here: the host does not resolve, and no cache can answer for it.

What remains after that is the box model, which is what this probe is for.
