A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page on the user's screen.

Browsers are used on a range of devices, including desktops, laptops, tablets, smartphones, smartwatches, smart televisions and consoles.

The purpose of a web browser is to fetch content and display it on the user's device. This process begins when the user inputs a Uniform Resource Locator into the browser's address bar.

Virtually all URLs on the Web start with either http: or https: which means they are retrieved with the Hypertext Transfer Protocol.

Requisite materials, including text, style sheets, images, and other types of multimedia, are downloaded from the server.

Once the materials have been downloaded, the web browser's engine converts those resources into an interactive visual representation of the page on the user's device.

Modern web browsers also contain separate JavaScript engines which enable more complex interactive applications inside the browser.

A web browser that does not render a graphical user interface is known as a headless browser.
